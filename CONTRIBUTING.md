# Contributing to OpenCanvas

Thank you for your interest in improving OpenCanvas. We welcome contributions to help build a better, distraction-free research platform.

## How to Contribute

1.  **Report Issues:** Use the issue tracker to report bugs or propose new features. Provide clear reproduction steps for bugs and a solid rationale for feature requests.
2.  **Claim an Issue:** Look for issues tagged `good first issue` or `help wanted`. Comment on the issue to claim it so others know it is being worked on.
3.  **Submit a Pull Request (PR):**
    *   Fork the repository and create a feature branch (`feature/your-feature-name`).
    *   Write clean, documented code that aligns with the existing architecture.
    *   Keep commits atomic and use descriptive commit messages.
    *   Test your changes thoroughly before opening a PR against the `main` branch.
    *   Link the relevant issue in your PR description.
